ポーズ写真の置き場所

このフォルダに写真を入れると、アプリの「ポージング」タブに自動で表示されます。

ファイル名のルール（番号順に並びます）:
  単身      … solo-1.jpg,   solo-2.jpg,   solo-3.jpg   ...
  カップル  … couple-1.jpg, couple-2.jpg, couple-3.jpg ...
  ファミリー … family-1.jpg, family-2.jpg, family-3.jpg ...
  団体      … group-1.jpg,  group-2.jpg,  group-3.jpg  ...

.jpg / .png どちらでもOK（index.html の POSES 配列にファイル名を登録します）。
写真を渡していただければ、こちらで登録・配置します。
